# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project aims to
follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-06-21

First public release: a full rebuild of the portfolio from the ground up.

### Added

- Interactive 3D hero (React Three Fiber) with a hand-tuned retro-computer scene.
- Work, Projects, project detail, About, Research, Résumé, and Contact routes.
- Server-side contact pipeline: schema validation, honeypot, rate limiting, and
  optional reCAPTCHA verification with Resend delivery.
- Live usage counter wired to the ATS Screener's public stats.
- SEO and metadata layer: Open Graph, Twitter cards, JSON-LD, sitemap, robots.
- Accessibility baseline: skip link, focus management, and reduced-motion support.
